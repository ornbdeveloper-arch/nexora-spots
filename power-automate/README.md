# Power Automate

A exportação corporativa do fluxo não é distribuída neste repositório. Ela contém referências de ambiente, conexões e conta remetente.

Para produzir um exemplo publicável:

1. recrie o fluxo em uma solução separada e autorizada;
2. use connection references e variáveis de ambiente;
3. aponte para listas e contas de demonstração;
4. remova histórico, IDs e metadados da organização de origem;
5. teste criação, edição, participantes e cancelamento;
6. exporte somente após revisão de segurança e propriedade intelectual.

A lógica verificada está documentada em [Power Automate](../docs/power-automate.md).
